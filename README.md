# Handwritten Digit Recognition: Neural Network in C++

**Frankie Pothier and David McGowan**
**SENG 475 (Advanced C++), University of Victoria, Summer 2024**

A fully connected neural network built from scratch in C++17 to recognize handwritten digits from the MNIST dataset. No machine-learning frameworks were used. Forward propagation, backpropagation, and gradient descent are implemented by hand, with Eigen for the linear algebra and OpenCV for image handling. 

## Getting Started
The instructions below explain how to build, install, and run the program, including the demo, digit recognition, accuracy testing, and retraining the network.

Let $TOP_DIR denote the directory containing this README file.

Let $INSTALL_DIR denote the directory into which this software is to be installed.

To build and install the software, use the following commands:
    cd $TOP_DIR
    cmake -H. -Btmp_cmake -DCMAKE_INSTALL_PREFIX=$INSTALL_DIR
    cmake --build tmp_cmake --clean-first --target install

To run a demonstration, use the command:
    $INSTALL_DIR/bin/demo

The demonstration code above generates the test image set, located in the directory:
    $INSTALL_DIR/lib/images/testing_data
The demonstration code then inputs one of the test images into num_recognizer, which then outputs
its reading of the value. The correct value can be read as the first character of the filename.

If the demonstration script is not run, the test image set can be generated by running the
following commands, note the current directory MUST be $INSTALL_DIR.
    cd $INSTALL_DIR
    ./bin/convert_images

To use the num_recognizer program, the current directory MUST be $INSTALL_DIR.
Let $PATH_TO_IMAGE_FILE denote the image file to be input into the program.
The program accepts images of type .pgm .pnm .jpg .png

To read a character from an image file, use the following commands:
    cd $INSTALL_DIR
    ./bin/num_recognizer $PATH_TO_IMAGE_FILE 

To view more information from the output of num_recognizer, run it with the debug option,
using the following commands:
    cd $INSTALL_DIR
    ./bin/num_recognizer debug $PATH_TO_IMAGE_FILE 

To test the accuracy of num_recognizer, the test image set must be already generated.
Run the program with the following commands:
    cd $INSTALL_DIR
    ./bin/num_recognizer test 

The neural network weights and biases are already trained when the software is installed.
If one wants to train the network again, follow the steps below:

In order to train the network, the source file convert_images.cpp, located in $TOP_DIR/app/convert_images.cpp
must be edited in order to generate the training data (60 000 files in total).
After commenting out and uncommenting the specified lines, and rebuilding and reinstalling the software, 
the training image data set can be generated by running the following commands, 
note the current directory MUST be $INSTALL_DIR.
    cd $INSTALL_DIR
    ./bin/convert_images

After running the above commands, to run the training software, run the following commands, note
the current directory MUST be $INSTALL_DIR.
    cd $INSTALL_DIR
    ./bin/ann_trainer
